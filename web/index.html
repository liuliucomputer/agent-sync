⚡ Agent Sync 开源

多 AI Agent 对话记录双向同步 · 本仓库需本地运行后端才能访问真实数据

📦 开源地址 / 拉取并运行

git clone https://gitcode.net/<你的用户名>/agent-sync.git
cd agent-sync
python server.py
# 浏览器打开 http://localhost:8080
本项目为本地优先：后端运行在你自己的电脑上，才能读取 ~/.claude、~/.codex 等真实 Agent 目录实现同步。 纯云端实例无本地文件，仅供查看说明与演示。

🔑 访问验证

后端启动时会在控制台打印、并在项目目录生成 access_id.txt 写入本次访问 ID。 在下方输入该 ID 即可解锁。

⚡ Agent Sync 网页版

多 AI Agent 对话记录双向同步 · 后端运行在你本机，访问真实的 agent 数据目录

① 选择要同步的 Agent

未自动检测到的 Agent，可在右侧文本框粘贴其配置目录的绝对路径（如 Claude 的 C:\Users\你的用户名\.claude、WorkBuddy 的 C:\Users\你的用户名\.workbuddy）后勾选。
注意：网页版出于浏览器安全限制，无法像桌面版那样弹出文件夹选择并拿到绝对路径，只能手动粘贴路径。
